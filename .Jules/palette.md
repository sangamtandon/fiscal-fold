## 2024-05-24 - Interactive Element Semantic Tags & Screen Reader Accessibility
**Learning:** Replacing clickable `<div>` elements with native `<button>` tags significantly improves accessibility by enabling keyboard focus (via Tab) and native activation (via Space/Enter). However, when adding `aria-label`s, the label completely overrides the element's visible inner text for screen readers. Any dynamic information (like remaining budget amounts) present in the visible text must be explicitly included within the `aria-label` to avoid regressions in screen reader experiences.
**Action:** Always prefer native interactive HTML elements (like `<button>`). When applying `aria-label` to interactive elements containing critical dynamic text, ensure that text is interpolated into the label so screen reader users don't lose context. Hide purely decorative elements like emojis with `aria-hidden="true"`.
