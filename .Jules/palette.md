## 2024-05-24 - Interactive Divs to Native Buttons
**Learning:** In the Dashboard view, `quick-bucket` items and `macro-card__unallocated` elements were rendering as `<div>`s with `click` listeners instead of native buttons. Similarly, `macro-card` accordions lacked keyboard accessibility entirely. This is a common vanilla JS pattern where click events are preferred, but it drops screen reader support and keyboard-only access.
**Action:** Always favor native `<button type="button">` over `<div role="button">` for interactive elements to get keyboard support for free. When using `<div>`s out of necessity, remember to add `role="button"`, `tabindex="0"`, `aria-expanded` (if it toggles content), and handle Enter/Space keys via a `keydown` listener, ensuring `e.preventDefault()` is called to prevent unwanted scrolling on Spacebar.
