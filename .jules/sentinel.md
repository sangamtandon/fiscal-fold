## 2024-03-05 - XSS Vulnerability in Bucket Removal Confirmation
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in the `_handleRemoveBucket` function in `src/pages/settings.js`. The `bucket.name` and `bucket.emoji` were directly interpolated into an `innerHTML` string used to display a deletion confirmation dialog, without any escaping.
**Learning:** Because bucket names are user-controlled strings, a malicious user could craft a bucket name like `<img src=x onerror=alert(1)>` which would be executed when the confirmation dialog is triggered. The app heavily relies on vanilla JS string interpolation for rendering, making XSS a persistent risk.
**Prevention:** Every time user input or data that could be influenced by a user is inserted into an `innerHTML` template, it *must* be sanitized. In this vanilla JS setup, the `escapeHtml` utility from `src/utils/helpers.js` should be used consistently to wrap all dynamic variables in `innerHTML` blocks.
